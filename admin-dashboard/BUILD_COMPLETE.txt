DEPLOYMENT OPTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A: DEPLOY TO LINUX SERVER (Recommended)

  Local machine:
    $ scp -r build/web/* admin@your-server.com:/var/www/gps-tracker-admin/

  OR with automated script:
    $ ./build-and-deploy.sh --deploy admin@your-server.com

Option B: DEPLOY ON SERVER MACHINE

  Transfer admin-dashboard folder to server:
    $ scp -r admin-dashboard/* admin@server:/opt/admin-dashboard/

  Then on server:
    $ cd /opt/admin-dashboard
    $ flutter build web --release
    $ ./deploy-quick.sh

Option C: MANUAL DEPLOYMENT

  1. Transfer files:
     $ scp -r build/web/* admin@server:/var/www/gps-tracker-admin/

  2. Configure nginx:
     $ ssh admin@server
     $ sudo apt update && sudo apt install -y nginx
     $ sudo mkdir -p /var/www/gps-tracker-admin
     $ sudo chown -R www-data:www-data /var/www/gps-tracker-admin/

  3. Create nginx config at /etc/nginx/sites-available/gps-tracker-admin.conf:

     server {
         listen 80;
         server_name _;
         root /var/www/gps-tracker-admin;
         index index.html;
         
         location / {
             try_files $uri $uri/ /index.html;
         }
     }

  4. Enable site and restart:
     $ sudo ln -s /etc/nginx/sites-available/gps-tracker-admin.conf \
                   /etc/nginx/sites-enabled/
     $ sudo rm -f /etc/nginx/sites-enabled/default
     $ sudo systemctl restart nginx

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Can't access dashboard?
  • Check nginx is running: sudo systemctl status nginx
  • Check file permissions: sudo chmod -R 755 /var/www/gps-tracker-admin/
  • Check nginx logs: sudo tail -f /var/log/nginx/error.log

  Map features not working?
  • Clear browser cache (Ctrl+Shift+Del or Cmd+Shift+Del)
  • Check browser console for errors (F12)
  • Verify API endpoint is accessible

  Deployment failed?
  • Check disk space: df -h /var/www/
  • Verify file transfer: ls -la /var/www/gps-tracker-admin/
  • Restart from scratch: sudo rm -rf /var/www/gps-tracker-admin/* && redeploy
